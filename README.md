# Учебная практика: Информационная система по школьному предмету «Химия»

## 1. Описание проекта
Данный проект представляет собой разработку информационной системы, предназначенной для изучения школьного курса химии с использованием современных технологий разработки. 
Система структурирует учебный материал, предоставляет интерактивные справочные инструменты (в частности, таблицу Менделеева) и облегчает навигацию по темам. 

Тип работы: Практическая работа по учебной практике

---

## 2. Цель и задачи проекта
**Цель:** разработка информационной системы по предмету «Химия» на базе платформы .NET. 

**Задачи:**
- анализ предметной области и требований к обучающим системам,
- проектирование расширяемой архитектуры для добавления новых тем, реализация серверной части на языке C#, интеграция с СУБД PostgreSQL (через интерфейс pgAdmin 4),
- разработка клиентского интерфейса, реализация модуля поиска и отображения химических элементов, тестирование корректности обработки данных. 

**Область применения:**  
- образование
- самообразование
- школьное обучение

---

## 3. Функциональность
- изучение тем «Тела и вещества»
- «Физические и химические процессы»
- «Химические элементы»; удобное перемещение между разделами
- Вспомогательные функции: интерактивное отображение таблицы Менделеева, поиск химических элементов по названию или символу, отображение подробной информации об элементе, валидация пользовательского ввода с выводом сообщений об ошибках при некорректных данных 
**Ограничения:**
- ориентированность на школьную программу
- тестовый режим эксплуатации

---

## 4. Архитектура проекта
Тип архитектуры: клиент-сервер (REST API).

**Технологии:**
- C# (.NET Core / ASP.NET Core) для backend
- PostgreSQL в качестве СУБД, pgAdmin 4 для администрирования базы данных
- Entity Framework Core для ORM 

**Структура проекта:**
- `src/` — исходный код
- `backend/` — серверная часть
- `frontend/` — клиентская часть
- `docs/` — документация
- `tests/` — тесты

---

## 5. Установка и запуск

**Требования:**
- NET SDK 6.0/7.0/8.0+,
- PostgreSQL,
- pgAdmin
  
**Установка:**
```bash
git clone https://github.com/username/project.git
cd project
pip install -r requirements.txt
```

**Запуск:**
dotnet run (запуск серверного приложения)

---

## 6. Использование
- переходить между разделами через меню навигации,
- открывать интерактивную таблицу Менделеева,
- осуществлять поиск конкретных элементов, просматривать карточки элементов с характеристиками,
- получать уведомления при вводе некорректных поисковых запросов.

## 9. Результаты и выводы
- В ходе выполнения проекта была разработана информационная система на базе C# и PostgreSQL, позволяющая структурировать и визуализировать учебный материал по химии. 
- Использование надежной СУБД PostgreSQL обеспечивает целостность данных, а язык C# гарантирует производительность и типобезопасность backend-части.
